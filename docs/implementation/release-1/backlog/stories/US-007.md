# User Story: US-007 — Truy vấn và hiển thị danh sách chiến dịch thật trên Ad Account

**Tầng tài liệu**: Implementation Layer  
**Release**: release-1 (MVP Demo)  
**Traceability**: Map to [FR-07] trong [prd.md](../../prd.md)  
**Priority**: P0 (Must)  
**Estimable Effort**: ~1.5 Story Points  

---

## 1. User Story Statement

**As a** BAHA Demo Operator sau khi tạo quảng cáo  
**I want to** xem danh sách các chiến dịch quảng cáo hiện có trên Ad Account được truy vấn trực tiếp từ Meta API và có thể bấm làm mới dữ liệu  
**So that** tôi kiểm chứng được chiến dịch vừa tạo đã thực sự xuất hiện trên hệ thống của Meta với trạng thái và thông số chính xác  

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy Path — Tải danh sách chiến dịch thật từ Meta API]
- **Given** Người dùng đã chọn một Ad Account hợp lệ và chuyển sang tab "Chiến dịch" (Campaigns)
- **When** Trang được tải hoặc người dùng nhấn nút "Làm mới dữ liệu" (Refresh)
- **Then** Frontend gọi API `GET /api/campaigns?ad_account_id={ad_account_id}`
- **And** Backend gọi Meta endpoint `GET https://graph.facebook.com/v20.0/{ad_account_id}/campaigns?fields=id,name,objective,status,created_time`
- **And** Giao diện hiển thị bảng danh sách chiến dịch gồm: Tên chiến dịch, Campaign ID, Mục tiêu (`OUTCOME_TRAFFIC`), Trạng thái (`PAUSED`), và Ngày giờ tạo
- **And** Chiến dịch vừa tạo hiển thị ở đầu danh sách

### AC2: [Edge Case — Tài khoản quảng cáo mới chưa có chiến dịch nào]
- **Given** Ad Account được chọn là tài khoản mới và chưa từng chạy chiến dịch nào trên Meta
- **When** Backend truy vấn danh sách chiến dịch và Meta trả về `data: []`
- **Then** Giao diện hiển thị trạng thái rỗng (Empty state) với thông điệp: "Chưa có chiến dịch nào trên tài khoản này. Hãy bắt đầu bằng cách tạo một quảng cáo mới!"
- **And** Có nút liên kết tắt chuyển nhanh sang tab "Tạo quảng cáo" (Create Ad)

### AC3: [Negative Path — Meta API gặp sự cố hoặc Ad Account mất quyền truy cập]
- **Given** Ad Account bị thay đổi quyền hoặc token bị hết hạn khi đang xem danh sách
- **When** Người dùng nhấn nút Refresh
- **Then** Hệ thống hiển thị thông báo lỗi trung thực: "Không thể lấy danh sách chiến dịch từ Meta API: {safe_error_message}"
- **And** Tuyệt đối KHÔNG tự động hiển thị dữ liệu mẫu (mock data) mà không có nhãn cảnh báo rõ ràng

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC ĐỌC TRƯỚC KHI CODE)

> ⛔ **Cảnh báo cho AI Coding Agent**: Trước khi sinh hoặc sửa code cho User Story này, Agent BẮT BUỘC phải đọc và tuân thủ các tài liệu kiến trúc bất biến sau:

1. **Data Integrity Principle** ([NFR-02](../../prd.md#nfr-02--tính-trung-thực-của-dữ-liệu)):
   - 100% dữ liệu hiển thị trong bảng chiến dịch phải lấy từ Meta Marketing API. Nghiêm cấm dùng dữ liệu giả lập.
2. **API Design Standards** ([08-integration-architecture.md](../../../architecture/08-integration-architecture.md)):
   - Endpoint: `GET /api/campaigns?ad_account_id=act_...`.
   - Cung cấp query parameter kiểm tra bắt buộc `ad_account_id`.
3. **Frontend Architecture** ([13-frontend-architecture.md](../../../architecture/13-frontend-architecture.md)):
   - Quản lý trạng thái bằng React state hoặc SWR/React Query đơn giản, có cờ `isLoading` hiển thị spinner khi đang tải dữ liệu.
