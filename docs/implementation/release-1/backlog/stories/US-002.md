# User Story: US-002 — Tải và chọn Tài khoản quảng cáo (Ad Account)

**Tầng tài liệu**: Implementation Layer  
**Release**: release-1 (MVP Demo)  
**Traceability**: Map to [FR-02] trong [prd.md](../../prd.md)  
**Priority**: P0 (Must)  
**Estimable Effort**: ~1 Story Point  

---

## 1. User Story Statement

**As a** BAHA Demo Operator đã kết nối tài khoản Meta  
**I want to** xem danh sách các Ad Account mà tài khoản Facebook của tôi có quyền truy cập và chọn một tài khoản  
**So that** tôi chỉ định chính xác tài khoản quảng cáo sẽ dùng để tạo chiến dịch sản phẩm và trừ ngân sách thực tế  

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy Path — Tải danh sách và chọn Ad Account hợp lệ]
- **Given** Phiên làm việc đã kết nối Meta thành công
- **When** Người dùng truy cập màn hình chính hoặc nhấn dropdown "Chọn Ad Account"
- **Then** Frontend gọi API `GET /api/meta/ad-accounts`
- **And** Backend dùng token trong `meta_sessions` gọi endpoint `GET https://graph.facebook.com/v20.0/me/adaccounts?fields=id,name,account_id,currency,account_status`
- **And** Giao diện hiển thị danh sách các tài khoản với Tên tài khoản, Account ID (`act_...`) và đơn vị tiền tệ (`currency`)
- **When** Người dùng chọn một tài khoản
- **Then** Hệ thống ghi nhận Ad Account được chọn và kích hoạt bước tiếp theo

### AC2: [Edge Case — Tài khoản không có Ad Account hoặc chưa được cấp quyền]
- **Given** Tài khoản Facebook kết nối thành công nhưng chưa được gán quyền trên bất kỳ Ad Account nào của BAHA
- **When** Backend truy vấn danh sách Ad Accounts từ Meta API và nhận về mảng rỗng `data: []`
- **Then** Giao diện hiển thị trạng thái rỗng (Empty state) với thông điệp: "Không tìm thấy tài khoản quảng cáo nào liên kết với tài khoản Facebook này. Vui lòng kiểm tra quyền truy cập trên Meta Business Suite"
- **And** Nút tiếp tục tạo quảng cáo bị vô hiệu hóa

### AC3: [Negative Path — Token hết hạn hoặc Ad Account bị khóa (Disabled)]
- **Given** Token lưu trong phiên đã bị thu hồi hoặc Ad Account có trạng thái `account_status != 1` (bị hạn chế/vô hiệu hóa)
- **When** Backend gọi Meta API hoặc người dùng chọn tài khoản bị khóa
- **Then** Hệ thống hiển thị cảnh báo rõ ràng: "Tài khoản quảng cáo này đang bị hạn chế hoặc không đủ điều kiện phân phối quảng cáo"
- **And** Gợi ý người dùng chọn tài khoản khác hoặc thực hiện kết nối lại

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC ĐỌC TRƯỚC KHI CODE)

> ⛔ **Cảnh báo cho AI Coding Agent**: Trước khi sinh hoặc sửa code cho User Story này, Agent BẮT BUỘC phải đọc và tuân thủ các tài liệu kiến trúc bất biến sau:

1. **Security & Credential Protection** ([07-security-architecture.md](../../../architecture/07-security-architecture.md)):
   - Token lấy từ DB backend và gắn vào HTTP Header `Authorization: Bearer <token>` khi gọi sang Meta.
   - Tuyệt đối không hardcode ID tài khoản của BAHA trong mã nguồn backend hoặc frontend.
2. **API Design Standards** ([08-integration-architecture.md](../../../architecture/08-integration-architecture.md)):
   - Endpoint backend: `GET /api/meta/ad-accounts`.
   - Chuẩn hóa response trả về theo định dạng:
     `{"success": true, "data": [{"id": "act_123456", "name": "BAHA Demo Account", "currency": "VND"}]}`.
3. **Design Principles** ([09-design-principles.md](../../../architecture/09-design-principles.md)):
   - Hàm gọi API đặt trong `MetaClient.get_ad_accounts()`.
   - Router tiếp nhận tại `backend/app/routers/meta_assets.py`.
