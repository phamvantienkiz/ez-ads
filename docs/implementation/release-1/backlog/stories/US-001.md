# User Story: US-001 — Kết nối Facebook qua Meta OAuth và duy trì phiên

**Tầng tài liệu**: Implementation Layer  
**Release**: release-1 (MVP Demo)  
**Traceability**: Map to [FR-01, FR-09] trong [prd.md](../../prd.md)  
**Priority**: P0 (Must)  
**Estimable Effort**: ~2 Story Points

## 1. User Story Statement

**As a** BAHA Demo Operator chuẩn bị phiên demo  
**I want to** nhấn nút kết nối và đăng nhập tài khoản Facebook qua luồng Meta OAuth 2.0 an toàn  
**So that** ứng dụng được cấp quyền truy cập hợp lệ để thao tác với Meta Marketing API và duy trì trạng thái đăng nhập khi tải lại trang  

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy Path — Kết nối Facebook thành công và lưu phiên]
- **Given** Người dùng đang ở màn hình chính và trạng thái kết nối hiển thị "Chưa kết nối"
- **When** Người dùng nhấn nút "Connect Facebook"
- **Then** Backend sinh URL đăng nhập OAuth kèm tham số `state` ngẫu nhiên lưu trong bộ nhớ tạm/cookie
- **And** Frontend chuyển hướng người dùng sang trang cấp quyền của Facebook
- **When** Người dùng đồng ý cấp đủ các quyền (`ads_management`, `ads_read`, `pages_read_engagement`, `pages_manage_ads`, `public_profile`)
- **Then** Meta chuyển hướng về callback URL `http://localhost:8000/api/meta/callback` kèm `code` và `state`
- **And** Backend xác minh tính hợp lệ của `state`, gửi request lên Meta đổi `code` lấy User Access Token
- **And** Backend lưu Access Token vào bảng SQLite `meta_sessions` với `id=1`
- **And** Trạng thái trên giao diện chuyển thành "Đã kết nối Meta" (Connected)

### AC2: [Edge Case — Tải lại trang (F5) hoặc restart backend không bị mất kết nối]
- **Given** Đã kết nối Meta thành công và bản ghi `meta_sessions` đã tồn tại trong SQLite
- **When** Người dùng tải lại trang trên trình duyệt hoặc backend server uvicorn được khởi động lại
- **Then** Frontend gọi API `GET /api/meta/status`
- **And** Backend kiểm tra token trong bảng `meta_sessions` còn hạn
- **And** Giao diện vẫn hiển thị trạng thái "Đã kết nối Meta", không yêu cầu đăng nhập lại

### AC3: [Negative Path — Người dùng hủy bỏ hoặc từ chối cấp quyền trên Facebook]
- **Given** Người dùng đang ở màn hình ủy quyền của Facebook
- **When** Người dùng nhấn nút "Hủy" (Cancel) hoặc từ chối cấp quyền
- **Then** Meta trả về callback kèm tham số lỗi (`error=access_denied`)
- **And** Backend bắt lỗi, điều hướng về frontend kèm thông báo: "Bạn đã từ chối cấp quyền kết nối Meta. Vui lòng thử lại để tiếp tục"
- **And** Không có bản ghi token rác nào được lưu vào cơ sở dữ liệu

### AC4: [Security — CSRF State Mismatch hoặc Callback giả mạo]
- **Given** Một request gọi trực tiếp tới `/api/meta/callback` không có `state` hoặc `state` không khớp với giá trị backend đã sinh ra
- **When** Backend kiểm tra tham số `state`
- **Then** Backend từ chối xử lý, trả về mã lỗi HTTP 400 Bad Request với thông điệp an toàn: "Yêu cầu xác thực không hợp lệ (CSRF detected)"
- **And** Không thực hiện gọi đổi token sang Meta Graph API

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC ĐỌC TRƯỚC KHI CODE)

> ⛔ **Cảnh báo cho AI Coding Agent**: Trước khi sinh hoặc sửa code cho User Story này, Agent BẮT BUỘC phải đọc và tuân thủ các tài liệu kiến trúc bất biến sau:

1. **Data Model Guardrails** ([05-data-architecture.md](../../../architecture/05-data-architecture.md)):
   - Bảng thao tác duy nhất: `meta_sessions` (gồm các cột: `id`, `access_token`, `token_type`, `expires_at`, `created_at`, `updated_at`).
   - Luôn duy trì duy nhất 1 bản ghi với `id=1` phục vụ cho phiên demo. Tuyệt đối không tạo bảng người dùng phức tạp.
2. **Security & Auth Guardrails** ([07-security-architecture.md](../../../architecture/07-security-architecture.md)):
   - `META_APP_SECRET` chỉ được đọc từ biến môi trường tại backend. Tuyệt đối không gửi Secret về frontend.
   - Không log toàn bộ callback URL chứa `code` hoặc plain-text Access Token vào console logs.
   - Không trả Access Token trong payload JSON trả về cho trình duyệt.
3. **Design Principles & Layout** ([09-design-principles.md](../../../architecture/09-design-principles.md) & [10-folder-structure.md](../../../architecture/10-folder-structure.md)):
   - Xử lý OAuth tại `backend/app/routers/meta_auth.py` và `backend/app/services/meta_client.py`.
   - Kết nối DB và truy vấn session đặt tại `backend/app/repositories/session_repository.py`.
