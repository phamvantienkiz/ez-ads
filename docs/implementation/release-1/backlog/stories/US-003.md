# User Story: US-003 — Tải và chọn Facebook Fanpage đại diện

**Tầng tài liệu**: Implementation Layer  
**Release**: release-1 (MVP Demo)  
**Traceability**: Map to [FR-03] trong [prd.md](../../prd.md)  
**Priority**: P0 (Must)  
**Estimable Effort**: ~1 Story Point

## 1. User Story Statement

**As a** BAHA Demo Operator đang cấu hình quảng cáo  
**I want to** xem danh sách các Facebook Page mà tôi có quyền quản lý và chọn một Fanpage  
**So that** Fanpage đó được sử dụng làm danh tính thương hiệu đại diện (`object_story_spec.page_id`) khi tạo mẫu quảng cáo sản phẩm  

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy Path — Tải danh sách và chọn Facebook Page thành công]
- **Given** Phiên làm việc đã kết nối Meta thành công
- **When** Người dùng truy cập form tạo quảng cáo hoặc mở dropdown "Chọn Fanpage"
- **Then** Frontend gọi API `GET /api/meta/pages`
- **And** Backend gọi endpoint `GET https://graph.facebook.com/v20.0/me/accounts?fields=id,name,category,tasks`
- **And** Giao diện hiển thị danh sách các Fanpage gồm Tên Page và Page ID
- **When** Người dùng chọn một Fanpage từ danh sách
- **Then** Hệ thống ghi nhận `page_id` được chọn để sẵn sàng gắn vào Ad Creative

### AC2: [Edge Case — Tài khoản không có Fanpage nào hoặc thiếu quyền quản lý quảng cáo]
- **Given** Tài khoản Facebook đăng nhập không sở hữu hoặc không được phân quyền quản trị/quảng cáo trên bất kỳ Fanpage nào
- **When** Backend truy vấn endpoint `/me/accounts` và nhận về `data: []`
- **Then** Giao diện hiển thị thông báo hướng dẫn: "Không tìm thấy Facebook Page nào bạn có quyền quản lý quảng cáo. Vui lòng tạo Page mới hoặc kiểm tra quyền trên Facebook"
- **And** Vô hiệu hóa nút tiếp tục tạo bài quảng cáo

### AC3: [Negative Path — Lỗi mất kết nối Meta API khi tải danh sách Page]
- **Given** Meta Graph API gặp sự cố chập chờn hoặc request timeout
- **When** Frontend yêu cầu tải danh sách Page
- **Then** Backend bắt exception `httpx.TimeoutException`, trả về lỗi chuẩn `{"success": false, "error": {"code": "META_API_TIMEOUT", "message": "Không thể kết nối đến máy chủ Meta để tải danh sách Trang. Vui lòng thử lại"}}`
- **And** Giao diện hiển thị nút "Thử lại" (Retry) cạnh dropdown
