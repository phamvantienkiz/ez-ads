## 2. Global Conventions & Standards (7 REST Patterns Applied)

### 2.1. Pattern 1: Versioning & Naming Compatibility Strategy
- **Chuẩn chính thức**: `/api/v1/...`
- **Chuẩn tương thích ngược (Alias)**: Hệ thống cung cấp alias `/api/...` (bao gồm cả `GET /api/ads/{id}` trỏ tới `GET /api/v1/ads/runs/{id}`) để khớp 100% với tài liệu Requirement gốc.
- **Tương thích Casing (`camelCase` & `snake_case`)**: Toàn bộ Pydantic V2 Schemas tại backend cấu hình `populate_by_name=True` (kèm `alias_generator=to_camel`), cho phép nhận request ở cả định dạng `camelCase` (`adAccountId`) lẫn `snake_case` (`ad_account_id`).

### 2.2. Pattern 7: Consistent Response Envelope

#### Khung phản hồi Thành công (Success Envelope):
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Thông điệp mô tả kết quả thành công",
  "data": {},
  "meta": {
    "timestamp": "2026-10-17T14:50:00Z",
    "requestId": "req_a1b2c3d4"
  }
}
```

#### Khung phản hồi Thất bại (Error Envelope):
```json
{
  "success": false,
  "statusCode": 400,
  "message": "Thông điệp lỗi an toàn hiển thị cho người dùng",
  "error": {
    "code": "ERROR_CODE",
    "details": []
  },
  "meta": {
    "timestamp": "2026-10-17T14:50:00Z",
    "requestId": "req_a1b2c3d4"
  }
}
```

### 3.2. Meta OAuth Authentication & Session Management

#### `GET /api/v1/meta/connect`
Khởi tạo phiên đăng nhập Meta, sinh chuỗi `state` ngẫu nhiên lưu vào cookie/in-memory session để chống tấn công CSRF, và trả về URL ủy quyền của Facebook.

- **Query Parameters**: Không.
- **Response `200 OK`**:
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Khởi tạo URL OAuth thành công",
  "data": {
    "authUrl": "https://www.facebook.com/v20.0/dialog/oauth?client_id=123456789&redirect_uri=http%3A%2F%2Flocalhost%3A8000%2Fapi%2Fmeta%2Fcallback&scope=ads_management%2Cads_read%2Cpages_read_engagement%2Cpages_manage_ads%2Cpublic_profile&state=rnd_state_987654321&response_type=code"
  },
  "meta": {
    "timestamp": "2026-10-17T14:50:00Z",
    "requestId": "req_auth_01"
  }
}
```

---

#### `GET /api/v1/meta/callback`
Endpoint tiếp nhận chuyển hướng (Redirect Callback) từ Facebook sau khi người dùng phê duyệt hoặc từ chối cấp quyền.

- **Query Parameters**:
  - `code` (string, optional): Authorization code từ Facebook.
  - `state` (string, required): Mã nonce xác thực đối soát CSRF.
  - `error` (string, optional): Mã lỗi nếu người dùng từ chối cấp quyền (`access_denied`).
  - `error_description` (string, optional): Diễn giải lỗi từ Facebook.
- **Xử lý**:
  - Nếu `error` tồn tại $\rightarrow$ redirect về `http://localhost:3000/?error=access_denied`.
  - Nếu `state` mismatch $\rightarrow$ trả về HTTP 400 Bad Request với mã `CSRF_MISMATCH`.
  - Nếu hợp lệ $\rightarrow$ gọi endpoint `POST /oauth/access_token` của Meta lấy token, lưu vào bảng `meta_sessions (id=1)`, và redirect 302 về `http://localhost:3000/?connected=true`.

#### `POST /api/v1/ads`
Thực thi chuỗi 5 lời gọi Meta Marketing API tạo quảng cáo sản phẩm thật (Image Hash $\rightarrow$ Campaign $\rightarrow$ Ad Set $\rightarrow$ Creative $\rightarrow$ Ad).

- **Request Headers**:
  - `Content-Type: application/json`
  - `X-Idempotency-Key` (string, optional): Khóa chống gửi trùng request.
- **Request Body Schema**:
```json
{
  "adAccountId": "act_1234567890",
  "pageId": "100200300400",
  "campaignName": "BAHA Polo Shirt Traffic Campaign",
  "budgetAmount": 50000,
  "primaryText": "Trải nghiệm dòng áo Polo nam cao cấp từ BAHA với chất liệu thoáng mát vượt trội.",

  "adName": "BAHA Polo Ad 1"
```

- **Validation Rules**:
  - `adAccountId`: Bắt buộc, chuỗi hợp lệ.

  - `campaignName`: Bắt buộc, độ dài từ 3 đến 255 ký tự.
  - `budgetAmount`: Bắt buộc, số dương (`> 0`).
  - `destinationUrl`: Bắt buộc, định dạng URL hợp lệ (`http://` hoặc `https://`).
  - `imageUrl`: Bắt buộc, URL ảnh hợp lệ có thể truy cập công khai.

## 4. Standardized Error Catalog (Từ điển mã lỗi)

| Mã lỗi (`error.code`) | HTTP Code | Nguyên nhân nghiệp vụ | Hướng xử lý gợi ý |
|---|:---:|---|---|
| `VALIDATION_ERROR` | 422 | Dữ liệu đầu vào sai định dạng (URL sai, thiếu trường) | Kiểm tra lại dữ liệu trong form |
| `SESSION_NOT_FOUND` | 401 | Chưa có token Meta hợp lệ trong cơ sở dữ liệu | Nhấn nút "Connect Facebook" |
| `TOKEN_EXPIRED` | 401 | Token phiên làm việc đã bị hết hạn hoặc thu hồi | Đăng nhập lại qua OAuth |
| `OAUTH_CSRF_MISMATCH` | 400 | Tham số `state` tại callback không khớp với backend | Bắt đầu lại luồng kết nối |
| `OAUTH_ACCESS_DENIED` | 400 | Người dùng hủy hoặc từ chối cấp quyền trên Meta | Cấp đủ các quyền được yêu cầu |
| `META_IMAGE_HASH_FAILED` | 400 | Không thể tải hoặc băm ảnh từ `imageUrl` | Kiểm tra xem ảnh có truy cập công khai được không |
| `PARTIAL_CREATION_FAILURE` | 400 | Lỗi ở một bước sau khi các bước trước đã thành công | Kiểm tra mã lỗi cụ thể của bước bị từ chối |
| `META_API_TIMEOUT` | 504 | Máy chủ Meta phản hồi quá chậm (> 30 giây) | Thử lại hoặc kiểm tra kết nối mạng |
| `DOUBLE_SUBMIT_LOCKED` | 409 | Yêu cầu tạo đang được xử lý, từ chối request trùng | Chờ tiến trình hiện tại hoàn tất |
